# Campus Lost & Found Portal

A small full-stack project made with HTML, CSS, JavaScript and Node.js. It uses Node's built-in modules, so no `npm install` is required.

## Run in VS Code terminal
1. Open this folder in VS Code.
2. Open Terminal > New Terminal.
3. Run `node server.js`.
4. Open `http://localhost:3000` in your browser.

## Features
- Add Lost or Found item reports
- View all reports
- Search reports
- Filter Lost / Found
- Mark an item as Returned
- Save reports in `data/items.json`

## Main files
- `public/app.js` - frontend logic
- `server.js` - backend and API
- `public/index.html` - page structure
- `public/style.css` - design
